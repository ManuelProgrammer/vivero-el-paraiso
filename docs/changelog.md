## Tipos de cambios

Cada entrada del changelog debe usar alguna de estas categorías:

- **Añadido** — Nuevas funcionalidades
- **Cambiado** — Cambios en funcionalidades existentes
- **Deprecado** — Funcionalidades que se eliminarán pronto
- **Eliminado** — Funcionalidades removidas
- **Corregido** — Corrección de errores (bugs)
- **Seguridad** — Correcciones relacionadas con vulnerabilidades

---

## ¿Cómo actualizar este archivo?

Cada vez que hagas un cambio significativo en el proyecto, agrega una entrada aquí **antes** de hacer el commit en Git. Ejemplo:

```
## [1.1.0] — 2026-04-15

### Añadido
- Página de favoritos funcional
- Botón de agregar/quitar favoritos en tarjeta de producto

### Corregido
- Error en el cálculo del total del carrito al aplicar descuentos
```
